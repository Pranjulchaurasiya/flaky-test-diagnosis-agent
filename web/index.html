FAILURE MODES

Flaky Test Taxonomy Matrix

Standardized taxonomy and signatures of non-deterministic CI failure patterns.

⚡
Race Condition

Unsynchronized concurrent threads or async tasks mutating shared dictionaries without atomic locks.

💧
Shared State Leak

Class-level singletons or global in-memory stores retaining mutated state between test instances.

⏱️
Timing / Sleep Drift

Hardcoded sleep() assumptions failing under CPU scheduler contention and CI runner latency spikes.

🔀
Order Dependence

Test assumes preceding tests populated database records; fails in isolated or randomized runs.

🌐
Flaky External Dependency

Unmocked socket/DNS/HTTP network calls to remote endpoints subject to connection refusal.

📁
Resource Exhaustion

Unclosed file handles or connection pool leaks causing OS permission and descriptor starvation.

🕰️
DateTime / Clock Drift

Mixing naive datetime.now() with UTC-aware timestamps or midnight date boundary roll-overs.

🎲
Unseeded Randomness

Non-deterministic random choice generators producing edge cases that fail strict validation logic.

🧪
Environment Mutation

Direct os.environ mutations without teardown monkeypatching, contaminating downstream test suites.

⚠️
Hard Ambiguous Case

Apparent timeout errors caused by uncoordinated async socket initialization and TIME_WAIT collisions.

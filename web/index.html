Flaky Test Taxonomy Matrix

Comprehensive classification of non-deterministic failure modes in modern software systems.

⚡
Race Condition

Unsynchronized concurrent threads or async tasks mutating shared dictionaries/state.

💧
Shared State Leak

Class-level singletons or global caches not purged between independent test instances.

⏱️
Timing / Sleep Drift

Hardcoded sleep() intervals failing under CPU load or scheduler latency fluctuations.

🔀
Order Dependence

Test assumes preceding tests populated database records; fails in isolated or shuffled runs.

🌐
Flaky External Dependency

Unmocked socket/DNS/HTTP requests to remote endpoints subject to network drops.

📁
Resource Exhaustion

Unclosed file handles or connection pool leaks causing OS permission and descriptor errors.

🕰️
DateTime / Clock Drift

Mixing naive datetime.now() with UTC-aware datetime or midnight clock boundary roll-overs.

🎲
Unseeded Randomness

Non-deterministic random token generators producing edge cases that fail validators.

🧪
Environment Mutation

Direct os.environ mutations without teardown monkeypatching, contaminating downstream tests.

⚠️
Hard Ambiguous Case

Apparent timeout errors caused by socket TIME_WAIT port collisions without SO_REUSEADDR.
